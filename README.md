# dashboard

A personal dashboard with weather and quotes loaded from local JSON files, and a personal task list saved in the browser.

## Live Site (https://ameliaeberle6-hue.github.io/dashboard/)

## Features

- Weather widget loaded from `data/weather.json`
- Quotes widget loaded from `data/quotes.json`
- Tasks widget with add, complete, and delete actions, saved in localStorage
- Responsive grid that brings the three widgets together
- Dark/light theme toggle saved with localStorage
- Readable at WCAG contrast in both themes

## Built With

HTML, CSS , and JavaScript
